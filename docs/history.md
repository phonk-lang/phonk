# Phonk History

The Phonk Programming Language began as a final project for an AP Computer Science A class.
The project started in May 2026, with the initial goal of compiling a small Phonk source file.

> Fun Fact: Phonk was originally named P.H.O.N.K. (The Procedural Hybrid Object Network Kit Programming Language).
> Classmates in the AP Computer Science classes voted on the name.

The Phonk compiler has always included a lexer, parser, and AST; however, the compiler's backend has evolved.
Initially, Phonk source code was transpiled to C++ and then compiled by another toolkit such as gcc/clang.
